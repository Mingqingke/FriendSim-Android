使用指南

装、配、出问题

按顺序看，大部分问题能自己解决。

01

安装与升级

允许安装未知来源应用后点击 APK。升级直接覆盖安装，聊天、角色、记忆都会保留，前提是签名没变。

02

配置 AI 接口

设置 → 对话 → 高级：填 API Key 与 Base URL（OpenAI 兼容格式）。不填就走公共端点，或打开「仅离线」。

03

角色

新建时填关系、性格、喜好、雷区、共同回忆。填得越具体，它越像那个人；留空就是通用朋友。

04

记忆

设置 → 记忆管理：按角色查看画像与情节，逐条删除或整角色清空。删掉的内容不会再出现在上下文里。

05

语音

按住说话发送语音。要让对方用你的音色回话，需要在电脑上跑 GPT-SoVITS 桥接，在设置 → 语音填地址；连不上会退回系统朗读。

06

备份

设置 → 隐私与数据导出整包备份。恢复前会校验文件，确认框里写明会覆盖哪些内容。

07

更新失败

更新器依次尝试 GitHub 接口、jsDelivr、raw，下载还会切镜像。全失败就去 Releases 手动下载，核对 SHA-256。

08

诊断

设置 → 运行诊断：网络、AI 接口、更新服务、存储四项真检查，失败会写清楚是哪一步。

排错

常见症状

一直提示「未配置 AI」

进设置 → 对话 → 高级确认 Key 和地址都填了，再点一下「验证连通性」。地址需要以 /v1 结尾（多数服务如此）。

录音发出去是空的

检查麦克风权限是否被系统回收。如果环境很安静，波形会很低，这是正常的。

语音条没声音

如果是克隆音色，说明桥接没连上，此时会退回系统朗读；系统朗读也没声音就去系统设置里检查 TTS 引擎。

安装时报签名不一致

手机上装过别的渠道包。先卸载旧包再装会丢失本地数据，建议先导出备份。

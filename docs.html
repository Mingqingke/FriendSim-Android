使用指南

装、用、出问题时先看这里。

安装与升级

下载 APK 后需要在系统设置里允许安装未知来源应用。升级直接覆盖安装，聊天记录、角色、记忆都会保留——只要签名没换。

AI 配置

设置 → 对话 → 高级：填 API Key 和 Base URL（兼容 OpenAI 格式）。不填就走公共端点，或者打开「仅离线」用本地的规则回复。

角色与记忆

新建角色时可以填关系、性格、喜好、雷区和共同回忆。记忆在设置 → 记忆管理里按角色查看，可以逐条删除，删掉的内容不会再进入对话上下文。

语音

按住输入框旁边的按钮说话，松手发送。要让对方用你的参考音色回话，需要在电脑上跑一个桥接服务并在设置 → 语音里填地址；连不上会退回系统朗读，这不是故障。

备份与恢复

设置 → 隐私与数据可以导出整包备份。恢复前会校验文件，覆盖范围会在确认框里写清楚。

更新失败

应用会依次尝试 GitHub 接口、jsDelivr 和 raw 三个来源，下载还会切换镜像。全都失败时去 Releases 页手动下载，用页面上的 SHA-256 核对后覆盖安装。

隐私与许可

数据只存在本机，用 Android Keystore 派生的密钥加密。项目以 GPL-3.0 发布，源码在 GitHub。

它能做什么

下面这些都在应用里真实存在，不是预告。

自己写的角色

关系、性格、喜恶、雷区、共同回忆都可以填。填了雷区，它真的会在那句话上炸。

记得住

长期记忆分角色保存，聊得越久越像个熟人。记忆可以在设置里逐条查看和删除。

语音条

按住说话，对方可以回语音。合成优先走你自建的克隆桥接，连不上就退到系统朗读。

像真人在打字

回复延迟跟着心情走，文字一个字一个字冒出来，气泡尾巴和圆角按消息分组变化。

数据只在本机

聊天、角色、记忆、录音都存在本机，用 Keystore 派生的密钥加密，不上传服务器。

三种脑袋

自备 API Key、免 Key 公共端点、完全离线三档降级。没网也能聊。

备份与导出

整包加密备份，恢复前先校验；聊天可以导出成长图。

图标伪装

桌面显示成计算器或备忘录，点开才是它。

常见问题

需要 API Key 吗？

不强制。可以填自己的 Key 走你选的模型，也可以走公共端点，或者干脆用离线模式——离线模式回复比较朴素，但完全不需要网络。

聊天记录会上传吗？

不会。数据存在本机并加密。只有当你配置了第三方模型服务时，对话内容才会发给你配置的那个服务。

语音克隆要装东西吗？

要。本机不跑克隆模型，需要在电脑上跑一个桥接服务，在设置里填地址。连不上时会退回系统朗读。

怎么升级？

应用内「关于 → 检查更新」会读 GitHub 上的版本信息，直接下载新包覆盖安装，数据不会丢。

更新失败怎么办？

多源会自动切换。还不行就从 Releases 页手动下载，SHA-256 可以对一下。

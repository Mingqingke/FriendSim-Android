它现在能做什么

下面每一条，都是应用里跑着的功能

01

自己写的角色

关系、性格、喜恶、雷区、共同回忆。填了雷区，它真的会在那句话上炸。

02

长期记忆

记忆按角色分开保存，设置里能逐条看、逐条删。删掉的不再进入上下文。

03

语音条

按住说话，对方可以回语音。合成优先走自建桥接，连不上退回系统朗读，会如实告诉你。

04

像真人在打字

延迟跟心情走，文字一个字一个字冒出来，气泡圆角与尾巴按消息分组变化。

05

三档降级

自备 Key、公共端点、完全离线。没网也能聊，只是回复朴素些。

06

本地加密

聊天、角色、记忆、录音都在本机，用 Keystore 派生的密钥加密，不上传服务器。

07

备份与导出

整包加密备份，恢复前校验。对话可以导出成长图。

08

运行诊断

网络、接口、更新、存储四项真检查，检查失败会写清楚失败在哪。

09

图标伪装

桌面上显示成计算器或备忘录，点开才是它。

常见问题

几个会被问到的问题

必须填 API Key 吗

不必须。可以填自己的 Key，也可以走公共端点，或者直接开离线模式。离线模式不联网，回复靠本地规则。

聊天记录会上传吗

不会上传到我们的服务器——这个项目没有服务器。只有当你自己配置了模型接口时，那一轮对话内容才会发给你配置的服务。

语音克隆要额外装东西吗

要。本机不跑克隆模型，需要在电脑上跑一个桥接服务，把地址填进设置。连不上会退回系统朗读。

怎么升级

应用内「关于 → 检查更新」读取版本信息后直接下载覆盖安装，数据保留。也可以在官网重新下包覆盖。

更新失败怎么办

更新器会依次换下载源。全失败就去 Releases 手动下载，用官网的 SHA-256 核对。
